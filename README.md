# Perishable inventory routing: stock-age policies, stochastic lookahead and decision-focused learning

Replication package for the revised IJPE manuscript
*Replenishing perishables on shared delivery routes: Stock-age-based inventory policies, stochastic lookahead and decision-focused learning* (`revision_1/manuscript.tex`).

The study simulates a periodic-review perishable inventory-routing system (10 stores, 2 vehicles, fixed shelf life, FIFO issuing, lost sales, shelf capacity) under contextual demand and compares nine replenishment policies in closed loop with identical information:

| Family | Policies |
|---|---|
| Inventory rules, route second | BSP (base-stock), BSP-EW (base-stock + estimated waste), UL_lambda (Crama et al. 2018) |
| Rolling-horizon PIRP MILP | LA-Mean, LA-Quantile, LA-Robust (budgeted uncertainty), ScenPO-SS (Jia et al. 2025), LA-DFL (proposed) |
| Reference | PI (lookahead with realised demand) |

Demand is generated by a documented contextual negative-binomial model (`pirp/demand.py`); no retailer data are used.

## Layout

```
pirp/            model, simulator, exact routing, MILPs, forecasts, policies, DFL, evaluation
experiments/     run_config.py (tune/train/evaluate one configuration), verify_theory.py,
                 make_figures.py (tables/figures for the manuscript), run_all.sh
tests/           unit tests (FIFO dynamics, exact TSP/CVRP, MILP feasibility, targets)
results/         outputs per configuration (cache/ is regenerated and not versioned)
revision_1/      manuscript.tex (+ sections/, figures/), references.bib, cover letter,
                 title page, revision plan, rejection letter, literature matrix
paper/           rejected submission (local only, not versioned)
```

## Reproduce

Python 3.12 with the packages in `requirements.txt` (the repository's `.venv` was used).

```bash
python -m pytest -q
python -m experiments.verify_theory --out results/theory
python -m experiments.run_config --config base --out results/base
python -m experiments.make_figures --results results --out revision_1/figures
```

`bash experiments/run_all.sh` runs every configuration (base, shelf life 2/4, lost-sales penalty 10/40, fleet ratio 1.10/1.60, high variability, partial LIFO). Each configuration takes roughly 45-60 minutes with 15 worker processes on a 16-core machine.

Each `results/<config>/` folder contains:

* `validation_tuning.csv` - closed-loop validation cost of every parameter setting;
* `dfl_training.csv` - DFL training loss and validation cost per epoch;
* `test_episodes.csv` - per-episode outcomes of every policy (cost components, fill rate, waste, visits, solver statistics, store-level service);
* `test_summary.csv`, `paired_tests.csv` - means and paired episode-level tests (bootstrap CI, t-test, Wilcoxon, Holm);
* `manifest.json` - configuration, chosen parameters, seeds and software versions.

The manuscript is compiled with `latexmk -pdf manuscript.tex` inside `revision_1/`.

## Notes on scope

* Lookahead MILPs are solved by HiGHS (via SciPy) to a 0.5% proven gap; routing binaries are kept for the implemented day and relaxed on later lookahead days, and day-0 routes are re-optimised exactly.
* ScenPO-SS is adapted to perishable FIFO dynamics with lost sales and uses the shared LightGBM quantile forecasts instead of an MQ-RNN.
* The earlier submission's M5-calibration, 81-cell factorial, regret and speed-up claims are withdrawn; its code and results were removed and remain in the git history.
