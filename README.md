## 📌 Overview

Perishable cold chains (fresh produce, biopharmaceuticals, dairy) require simultaneous multi-period inventory replenishment and capacitated vehicle routing under volatile customer demand and strictly finite shelf lives ($\tau \in \{2, 3, 5\}$ periods). 

In conventional **Predict-then-Optimize (PTO)** pipelines, demand forecasts are trained by minimizing symmetric statistical errors (e.g., Mean Squared Error):
$$\mathcal{L}_{\text{MSE}}(\theta) = \frac{1}{NT}\sum_{i=1}^N \sum_{t=1}^T \left(\hat{d}_{it}(x_{it}; \theta) - d_{it}\right)^2$$
and then plugged into downstream Mixed-Integer Linear Programs (MILPs).

However, in perishable operations, forecast errors have severe **asymmetric economic penalties**:
- **Over-forecasting** generates excess stock that reaches expiration age $\tau$, triggering waste and disposal penalties ($p_s = 5h$).
- **Under-forecasting** depletes store inventory, causing punitive emergency replenishment or lost-sales penalties ($p_u \in \{10h, 20h, 50h\}$).
- **Vehicle Routing Discontinuities**: If forecast errors cross vehicle payload capacity $Q$, an entire additional vehicle route must be dispatched, incurring steep fixed vehicle activation and travel distance costs.

**Two-Phase-DFL** resolves this fundamental decoupling through:
1. **Exact Linear Recourse Reformulation**: Maps uncertain demand from the right-hand-side inventory constraints into the objective function via explicit emergency replenishment ($y_{it}^+ \ge 0$) and spoilage disposal ($y_{it}^- \ge 0$) recourse variables, guaranteeing **Complete Recourse** and unconditional solver feasibility.
2. **Surrogate Gradient Mechanisms**: Evaluates and compares Smart Predict-then-Optimize (SPO+), Interior Point Differentiation (IntOpt), and Differentiable Perturbed Optimizers (DPO).
3. **Two-Phase Training Protocol**: Trains on continuous Linear Programming (LP) relaxations during early epochs ($E_{\text{trans}} = 75\%$) for gradient smoothing and rapid feature alignment, transitioning to discrete MILP fine-tuning for exact combinatorial convergence.

| :--- | :--- | :---: | :---: | :---: | :---: |

| Single-Phase DFL | IntOpt MILP | 25.10% | ±0.12% | $2,193.10 | $p = 0.0309$ |

## ⚡ Quick Start & Verification

### 1. Installation

Clone the repository and install requirements in a virtual environment:

```bash
git clone https://github.com/DeckardShaw31/Two-Phase-DFL.git
cd Two-Phase-DFL

# Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

*Note: The optimization engine supports both **Gurobi** (`gurobipy`) and open-source solvers (**HiGHS** / **SciPy**) with automatic fallback.*

### 2. Instant Reproducibility Verification (< 1 second)

Audit and verify numerical parity across all benchmark results, metric tables, and manuscript figures:

```bash
python src/experiments/reproduce_all.py --verify
```
