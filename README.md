# Perishable inventory routing: stock-age policies, stochastic lookahead and decision-focused learning

Replication package for the revised IJPE manuscript
*Replenishing perishables on shared delivery routes: Stock-age-based inventory policies, stochastic lookahead and decision-focused learning* (`revision_1/manuscript.tex`).

The study simulates a periodic-review perishable inventory-routing system (10 stores, 2 vehicles, fixed shelf life, FIFO issuing, lost sales, shelf capacity) under contextual demand and compares twelve replenishment policies in closed loop with identical information:

| Family | Policies |
|---|---|
| Inventory rules, route second | BSP (base-stock), BSP-EW (base-stock + estimated waste), UL_lambda (Crama et al. 2018) |
| Learned rules | UL-DFL (proposed: decision-focused order-up-to levels), NN-DFL (ablation without the rule) |
| Rolling-horizon PIRP MILP | LA-Mean, LA-Quantile, LA-Quantile2, LA-Robust (budgeted uncertainty), ScenPO-SS (Jia et al. 2025), LA-DFL (proposed) |
| Reference | PI (lookahead with realised demand) |

Synthetic demand is generated by a documented contextual negative-binomial model (`pirp/demand.py`); the real-data case uses the public FreshRetailNet-50K dataset (`pirp/fresh.py`, see `data/freshretailnet_raw/README.md`).

## Layout

```
pirp/            model, simulator, exact routing, MILPs, forecasts, policies, DFL, evaluation
experiments/     run_config.py (tune/train/evaluate one configuration), verify_theory.py,
                 retune_ul.py, retrain_uldfl.py, rerun_scenpo.py, fold_results.py,
                 fresh_test.py, rule_frontier.py, analyze_uldfl.py, analyze_dfl.py,
                 solver_sensitivity.py, make_figures.py (tables/figures), run_chunk.sh
tests/           unit tests (FIFO dynamics, exact TSP/CVRP, MILP feasibility, targets)
results_v2/      outputs of the final study per configuration; base_fresh/ holds the fresh
                 base-case test episodes (primary hypotheses)
results/         earlier round of the study and the data cache (cache/ is not versioned)
revision_1/      manuscript.tex (+ sections/, figures/), references.bib, cover letter,
                 title page, revision plan, rejection letter, literature matrix
paper/           rejected submission (local only, not versioned)
```

## Reproduce

Python 3.12 with the packages in `requirements.txt` (the repository's `.venv` was used).

```bash
python -m pytest -q
python -m experiments.verify_theory --out results/theory
bash experiments/run_chunk.sh 4 13 python          # all 13 configurations into results_v2/ (chunked)
python -m experiments.retune_ul --results results_v2        # UL_lambda on the fine grid (validation only)
python -m experiments.retrain_uldfl --results results_v2    # UL-DFL trained from the re-tuned rule
python -m experiments.rerun_scenpo --results results_v2     # ScenPO-SS with the scenario set of Jia et al.
python -m experiments.fold_results --results results_v2     # fold the final versions into the result files
python -m experiments.fresh_test --results results_v2       # base case on fresh test episodes
python -m experiments.rule_frontier --config base --results results_v2
python -m experiments.analyze_uldfl --run results_v2/base --config base --out revision_1/figures
python -m experiments.make_figures --results results_v2 --out revision_1/figures
```

A configuration takes 1-2.6 hours with 12-15 worker processes on a 16-core machine; the steps after `run_chunk.sh` take about five hours in total. Keep the computer awake during runs: HiGHS time limits count wall-clock time, and decisions solved while the machine sleeps can stop at the limit (check `nonoptimal` in `test_summary.csv`).

Each `results_v2/<config>/` folder contains:

* `validation_tuning.csv` - closed-loop validation cost of every parameter setting;
* `dfl_training.csv` - DFL training loss and validation cost per epoch;
* `test_episodes.csv` - per-episode outcomes of every policy (cost components, fill rate, waste, visits, solver statistics, store-level service); the first versions of the rule tuning, of UL-DFL and of ScenPO-SS are kept as `UL-coarse`, `UL-DFL-coarse` and `ScenPO-SS-bands`;
* `test_summary.csv`, `paired_tests.csv` - means and paired episode-level tests (bootstrap CI, t-test, Wilcoxon, Holm);
* `manifest.json` - configuration, chosen parameters, seeds and software versions.

The manuscript is compiled with `latexmk -pdf manuscript.tex` inside `revision_1/`.

## Notes on scope

* Lookahead MILPs are solved by HiGHS (via SciPy) to a 0.5% proven gap; routing binaries are kept for the implemented day and relaxed on later lookahead days, and day-0 routes are re-optimised exactly.
* ScenPO-SS uses the scenario set of Jia et al. (predicted deciles plus sampled scenarios, 20 in total), adapted to perishable FIFO dynamics with lost sales, with the shared LightGBM quantile forecasts instead of an MQ-RNN.
* The synthetic test episodes (seeds 9000+e) were also evaluated in an earlier round of the study (`results/`); the primary hypotheses are therefore tested on fresh base-case test episodes (seeds 20000+e, `results_v2/base_fresh/`).
* The earlier submission's M5-calibration, 81-cell factorial, regret and speed-up claims are withdrawn; its code and results were removed and remain in the git history.
