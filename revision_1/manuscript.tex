\section*{Data and code availability}
All code, configuration files, random seeds and result files needed to reproduce every table and figure are provided in the replication package (\texttt{pirp/}, \texttt{experiments/}, \texttt{results\_v2/}). The synthetic demand data are generated by the package. The real-data case uses the public FreshRetailNet-50K dataset \citep{wang2025freshretailnet} (CC BY 4.0), which is downloaded from Hugging Face as described in the package and then processed by its code; no proprietary data are used.
